## 👋 Chi sono

Sono un **QA Engineer specializzato in automazione dei test**. Il mio lavoro è far sì che il software funzioni davvero: progetto strategie di test, scrivo suite automatiche affidabili e le integro nelle pipeline, così ogni rilascio è più sicuro e più veloce.

Vengo dallo sviluppo web (HTML, CSS, PHP, Laravel): conosco il codice dal lato di chi lo scrive, ed è per questo che so dove tende a rompersi.

## 🎯 Cosa faccio

| Area | Cosa significa |
|---|---|
| 🧪 **Test automation** | Suite end-to-end, API e regressione, stabili e manutenibili |
| 🔁 **CI/CD** | Test eseguiti a ogni commit, report chiari, feedback in pochi minuti |
| 🧭 **Strategia di test** | Piramide dei test, analisi del rischio, copertura che serve davvero |
| 🐞 **Analisi dei difetti** | Bug riproducibili, con contesto e causa probabile, non solo "non funziona" |
| 🐍 **Automazione con Python** | Script e strumenti che tolgono lavoro ripetitivo al team |
